# 灶边 · 分步烹饪指导小程序

这是一个原生微信小程序 MVP，已完成：

- 菜谱搜索、横向分类推荐和上下滑动列表
- 按已有主要食材搜索菜谱、数量校验与缺少食材提示
- 本地收藏、烹饪历史、步骤进度保存与断点继续
- 烹饪历史单条删除（进行中的记录会同步清除计时与进度）
- 采购清单、一键加入食材、已采购标记与批量操作
- 个人主页、每日/每周完成报告和个人标签
- 过敏原自动隐藏或标注警示
- 每人份热量估算、慢跑时间换算与显示份数设置
- 屏幕常亮、计时声音、震动和继续询问开关
- 菜品详情、食材复杂度与烹饪难度评分
- 就餐人数调整与食材用量自动换算
- 主食材/调味料分组备菜清单
- 主食材缺料勾选与两道替代菜推荐（自动排除当前菜）
- AI 生成的菜品、食材和步骤图例
- 逐步烹饪、步骤进度和本地倒计时
- 计时未结束时的跳步二次确认
- 计时结束提示音、震动和完成烟花

## 在微信开发者工具中运行

1. 选择“导入项目”。
2. 项目目录选择本文件所在目录。
3. 项目已配置参赛小程序 AppID：`wxb6fe90024237c673`。导入时使用此 AppID；如需真机预览、上传或发布，请使用已获得该小程序开发权限的微信账号。
4. 点击编译，从首页选择任意菜谱即可体验完整流程。

## 当前菜谱范围

当前包含 120 道菜：原有 30 道、扩充菜谱 70 道和本轮新增的 20 道中式菜。新增菜均包含主要食材、调味料、分步指导、计时建议、安全提醒和公开菜谱检索来源；菜谱详情页会显示按常见食材热量与当前用量得出的估算值。

烹饪流程支持多道菜同时进行。每道菜分别保存当前步骤和计时结束时间；离开菜品页面后计时继续，小程序前台运行时会在任意页面响铃并弹窗提醒。首页等页面的“进行中的菜”悬浮入口可随时切换回任意一道菜。

## 后续建议

- 将大规模菜谱数据迁移到云数据库，图片迁移到云存储/CDN，避免超过小程序代码包大小限制。
- 接入可追溯的 AI 问答与步骤纠错能力，并为回答增加来源和安全边界。
- 用真实用户测试数据优化步骤文本、按钮位置和计时体验。
