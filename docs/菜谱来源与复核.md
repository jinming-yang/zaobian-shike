# 菜谱来源与复核记录

## 使用原则

1. 菜谱以常见、可复现、适合家庭厨房为首要标准，不追求唯一“正宗”版本。
2. 每道菜必须记录参考来源、复核日期、份量基准和食品安全提醒。
3. 不直接复制来源文字；根据家庭厨房场景重写后，再核对关键顺序、火候和时间。
4. 无可靠来源的菜谱只可作为“待复核草稿”，不能直接批量进入正式菜谱库。
5. 禽肉、肉末、鸡蛋和水产类菜谱需额外复核熟度判断、生熟分离与清洁提醒。

## 扩充流程

新增菜谱时先进入待审核区；完成来源核对、份量换算测试、步骤试做和食品安全检查后，才加入公开列表。来源发生变化时保留版本记录，不静默覆盖旧版。
