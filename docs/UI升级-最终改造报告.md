# 灶边食刻 UI 全局升级报告

## 完成范围

已将“奶油元气厨房”视觉系统推广至 9 个业务页面、4 个公共组件和自定义 TabBar：

- 首页：小灶欢迎区、搜索、快捷入口、分类、菜谱卡片及空状态。
- 按食材找菜：蛋仔介绍区、搜索建议、数量控件、匹配结果及状态标签。
- 菜谱详情：真实菜品主视觉、信息卡、营养、过敏原、分享和固定主操作。
- 备菜：人数换算、采购入口、食材与调味料、缺料推荐、切配任务和底部主操作。
- 分步烹饪：步骤图片、进度、计时状态、火候提示、多菜入口、退出弹窗和安全区。
- 完成页：角色庆祝区、菜品照片、周完成结果和分享入口。
- 采购清单：汇总、批量操作、购买状态、删除状态和蛋仔空状态。
- 个人中心：角色头像、设置入口、日报/周报、营养趋势、收藏和历史。
- 设置：奶油主题头图、标签、过敏原模式、步进器、开关和教程重播。
- 公共组件：教程、进行中菜品、营养卡片和自定义 TabBar。

## 设计系统

- `styles/theme.wxss`：颜色、文字、边框、圆角和阴影等语义令牌。
- `styles/theme-pages.wxss`：跨页面统一视觉覆盖层。
- `styles/theme-ornate.wxss`：参考“奶油元气厨房”视觉稿增加的华丽插画层，包含渐变底纹、橙黄双层描边、浮雕阴影、软糖按钮、彩色胶囊、图片相框、计时光晕、弹窗层次和空状态装饰。
- 深度构图调整：首页升级为小灶与蛋仔联合场景头图，并将食材匹配和采购入口重排为双列彩色功能卡；详情页使用菜品相框；备菜页使用分区料理手账；烹饪页使用插画操作台；个人中心、设置和采购清单使用杂志卡片和彩色纸片层次。
- 页面背景：`#FFF9F0`。
- 品牌主色：`#FF946D`。
- 黄油强调：`#FFD66B`。
- 薄荷状态色：`#9EDBC3`。
- 正文：`#59483F`。

## 素材生成方式

角色素材使用内置图像生成能力制作。提示词以原创 Q 版厨房角色、透明背景、奶油白/蜜桃橙/黄油黄/可可棕/薄荷绿配色、统一圆润线条、无文字、无水印、无现有商业 IP 特征为约束。运行时素材经过等比缩放与透明 PNG 优化。
