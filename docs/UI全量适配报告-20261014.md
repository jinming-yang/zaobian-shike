# 灶边食刻 · 奶油元气厨房全量适配报告

## 实际工程范围

项目包含 9 个页面：首页、我的、设置、采购清单、按食材找菜、菜谱详情、备菜、分步烹饪、完成页；包含活跃烹饪、食材图片、营养卡、新手教程 4 个公共组件，以及自定义底部导航。

## 本轮改造

- 首页：重构左右分区 Banner，真实文字固定两行；更新搜索框、双功能入口、插画分类标签和双列大图菜谱卡。
- 按食材找菜：更换正式食材料理台 Banner，保留搜索、增删数量和推荐逻辑。
- 菜谱详情：保留真实菜品照片为视觉中心，统一收藏、计时、营养与提示卡片。
- 备菜：使用食材料理台背景，保持人数换算、采购加入和缺料替代逻辑不变。
- 分步烹饪：强化步骤相框、进度条、计时状态和底部操作区，不修改计时逻辑。
- 采购清单：加入手绘锅具插画，统一待采购、已购买和批量操作状态。
- 我的：增加头像资料和收藏、记录、本周完成统计，保留报告、营养趋势、收藏与历史。
- 设置：加入手绘贴纸，统一标签、单选、步进器和开关区域。
- 完成页：加入透明蔬菜庆祝装饰，保留营养、分享和返回逻辑。
- 公共组件：营养卡和自定义底栏接入统一插画图标。
