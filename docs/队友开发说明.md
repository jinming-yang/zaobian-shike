# 队友开发说明

## 导入项目

1. 解压压缩包。
2. 在微信开发者工具中选择“导入项目”。
3. 项目目录选择解压后包含 `app.json`、`app.js` 和 `project.config.json` 的“灶边食刻-完整源码”文件夹。
4. AppID 为 `wxb6fe90024237c673`，已写入项目配置。
5. 点击“编译”即可运行。此项目采用原生微信小程序结构，无需先安装 npm 依赖。

真机预览、上传和发布需使用拥有此小程序对应权限的微信账号。

## 修改入口

- `pages/`：首页、个人页、备菜页、详情页、设置等页面的布局、样式和逻辑。
- `components/`、`custom-tab-bar/`：公共组件、食材图片组件和自定义底部导航。
- `app.wxss`：全局样式和主要按钮颜色。
- `data/recipes.js`：统一输出 120 道菜的数据。其他 `recipes-*.js` 保存具体配方。
- `data/ingredient-guide.js`：食材与正确图片的对应关系、去皮去根等预处理说明。
- `utils/cooking-guidance.js`：不同烹饪方式的热油观察提示。
- `utils/cook-page.js`：所有烹饪分包共用的步骤、计时、上一步/下一步等逻辑。
- `pages/cook/cook.wxml`、`pages/cook/cook.wxss`：所有烹饪分包共用的页面布局和样式。
- `assets/`：主包中的菜品缩略图、食材图片及音频等资源。
- `food-images-1` 至 `food-images-4`：菜品高清图片分包。
- `step-images-1` 至 `step-images-12`：烹饪页面及步骤图片分包。
- `docs/`：项目和本轮修改说明。
- `tmp/`：检查脚本、辅助开发脚本及对应的轻量数据。

修改时保留图片分包结构与 `app.json` 的对应配置。当前主包文件本地估算约 1.39 MiB，最终大小以开发者工具打包结果为准。

## 可选检查

安装 Node.js 后，在项目目录运行以下现有检查。运行小程序本身不需要这一步。

```text
node tmp/check-beginner-guidance.js
node tmp/check-workflows.js
node tmp/check-previous-step.js
node tmp/check-cook-image-routing.js
node tmp/check-step-images.js
node tmp/verify-features.js
```

压缩包包含小程序全部源码、配置和现有图片音频资源，技术说明、检查脚本及轻量开发数据。未包含本机工具环境、生成图片的高清备份、缓存及参赛说明 Word 文档；这些内容不影响导入和修改小程序。
