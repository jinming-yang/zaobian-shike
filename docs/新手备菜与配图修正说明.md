# 新手备菜与配图修正

本次修正包括食材图片的逐项对应、开火前预处理清单，以及烹饪步骤中的热油观察点。

已核对 120 道菜、187 个食材名称和 142 张食材图，其中 80 张为本次补充的对应图片；140 个烹饪步骤显示热油观察提示。图片原文件已保留，主包文件本地估算约 1.39 MiB，最终以微信开发者工具打包结果为准。

## 使用方式

- 备菜页：在用量清单下方查看每项主要食材的清洗、去根、去皮、去筋和切配说明，可点击“标记备好”。本菜已有的切配要求另外显示。
- 烹饪页：相关步骤显示“新手观察点”，区分炒香、一般翻炒、煎制、黄油、炸制、淋油及冷油慢炸葱油。不需要等油冒烟，小烟也提示停火降温。
- 备菜、食材匹配和采购清单统一使用食材名称对应的图片，完整展示物体，避免裁切。食材缩略图随主包加载，显示失败可点击重试。

## 数据维护

食材名称、图片和预处理集中在 `data/ingredient-guide.js`；食材图片位于 `assets/images/ingredients/`。新增食材必须补全准确的图片和处理说明，不复用无关图片充当默认图。

照片采用内置 imagegen 生成。提示词要求：准确的指定食材、真实食材摄影、完整居中构图、四周留白、奶油白背景、柔和光线，无文字、水印或装饰。生成原始文件保留于 `tmp/ingredient-image-originals/`，提示词与主题记录于同目录下的生成清单。

一般清洗、削皮、切配说明是针对现有菜谱的编辑性补充；热油表面细纹和下锅声音属于观察提示，不能据此推定精确温度。复杂油炸采用热油温度计，并按具体炸制阶段调整。

## 核对来源

- [Good Food：安全油炸](https://www.bbcgoodfood.com/howto/guide/how-deep-fry-safely)：油冒烟时停火降温，炸制使用合适温度计，控制锅内油量。
- [USDA FSIS：食材清洗](https://www.fsis.usda.gov/food-safety/safe-food-handling-and-preparation/food-safety-basics/washing-food-does-it-promote-food)：蔬果用流动水清洗；冲洗生肉、生禽可能增加交叉污染。

以上来源支持相应的清洗和热油安全原则，具体食材切法仍以本菜步骤和实际包装说明为准。
